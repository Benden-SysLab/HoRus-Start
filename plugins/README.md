# HoRus-Start — Ansible Plugin Architecture

This directory houses custom Ansible extension plugins for the HoRus-Start platform:

- `filters/` — Custom Jinja2 filter plugins (e.g., `storage_filters.py`) for data transformation and normalization.
- `actions/` — Custom Ansible action plugins for reusable validation and workflow orchestration.
- `module_utils/` — Shared Python utilities and domain models.
